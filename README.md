# Banco Virtual

Projeto em Java que simula um sistema de conta bancária.

## Funcionalidades
- Criar conta bancária
- Definir tipo de conta (CC ou CP)
- Controle de saldo
- Pagamento de mensalidade
- Validação de status da conta

## Tecnologias
- Java
- Programação Orientada a Objetos

## Objetivo
Projeto desenvolvido para fins de estudo e prática de POO em Java.
